# Project Rules

- You are allowed to modify any code files necessary to fix bugs, optimize performance, and improve the application across all firmware and software components: `sys-esp32`, `rt-esp32`, `mtr-stm32`, `jetson`, `debug-tool`, `tem`, and `control-toolkit`.
- You are allowed to create and edit files in `sys-esp32`, `rt-esp32`, `mtr-stm32`, `jetson`, `debug-tool`, `tem`, and `control-toolkit` as needed.
- **Strict Anonymity & NDA Compliance**: Never mention or include vendor names, supplier names, manufacturer names, or specific proprietary actuator model numbers in any code, comments, documentation, commit messages, or responses. Refer to actuators and controllers strictly by their functional subsystem names: SES (Steering Actuator / Steer-by-Wire), SEB (Braking Actuator / Brake-by-Wire), MTR (Motor Controller / Inverter), VCU, RT, SYS, RM, HMI, etc.
