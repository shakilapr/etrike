# RT-AURIX-Lite CAN Protocol Subset

This directory is a **stripped, RT-only CAN protocol contract set** for the consolidated
realtime-AURIX (RT) controller described in [`../architecture.md`](../architecture.md).

It is produced from the repository's canonical protocol contracts
(`../../protocol/contracts/`) by the same generation scripts. The RT-only design merges the
former **RT** and **SYS** nodes into a single node named **`RT`** on the wire, removes all
RT↔SYS intercommunication, and re-homes SYS-owned messages under the `rta` owner.

## What changed versus the canonical protocol

| Aspect | Canonical (`protocol/`) | This subset (`rt-aurix-lite/protocol/`) |
| --- | --- | --- |
| Nodes | Host, RT, SYS, MTR, PWT, DCDC, EPS_C, SEB, HMI, Any | Host, RT, MTR, EPS_C, SEB, HMI, Any |
| Buses | high, low, powertrain | high, low |
| RT owner | `rt` | `rta` (realtime AURIX) |
| SYS node | present | removed (folded into RT) |
| `0x011` safety status | `sys:sys_safety_sts`, sender SYS | `rta:rta_safety_sts`, sender RT (high only) |
| `0x600` diag | `sys:sys_diag_rpt`, sender SYS | `rta:rta_diag_rpt`, sender RT (high only) |
| `0x110` mode | `sys:sys_mode_cmd`, sender SYS → RT, MTR | `rta:rta_mode_cmd`, sender RT → MTR |
| `0x7FE` SYS heartbeat | present | **removed** |
| `0x205` RT→SYS brake | present | **removed** (RT drives `0x7B9` directly) |
| `0x7B9` SEB command | sender SYS (dual-sender w/ RT) | sender RT (single sender) |
| `0x012` DC-DC / powertrain | `pwt` owner on powertrain bus | **removed** (no powertrain bus) |
| SES/SEB/MTR/Host/HMI wire layouts | unchanged | unchanged (byte-identical) |

> **Wire compatibility:** All retained messages keep their exact CAN ID, DLC, byte order,
> signal layout, and vendor checksum/rolling-counter algorithms from the canonical
> contracts. Only network/sender/instance metadata changed. The custom SES/SEB codecs and
> their language-neutral vectors are copied unchanged.

## Layout

```
rt-aurix-lite/protocol/
├── tools/               # parallel generator (generate.py) — does NOT modify protocol/tools
├── contracts/           # network.yaml + per-owner message contracts (rta, host, mtr, ses, seb, hmi)
├── generated/           # committed output of the generation tool
│   ├── cpp/             # C++ header (etrike_protocol.hpp)
│   ├── python/          # Python module (etrike_protocol.py)
│   ├── typescript/      # TypeScript module (etrike-protocol.ts)
│   ├── csv/             # per-bus and per-node CSV tables
│   ├── dbc/             # per-bus and per-node DBC files
│   ├── docs/            # per-bus and per-node Markdown reference
│   └── *.json           # discovery, capabilities, errors, contract-schema
└── vectors/             # language-neutral payload/sequence vectors (keys remapped to rta)
```

The generated codecs are self-contained (custom SES/SEB vendor payloads are handled inline);
the subset does not depend on `protocol/codecs`, `protocol/profiles`, or `protocol/compat`.

## Regenerating

This subset is a **parallel, self-contained protocol tree**. It is generated by the
dedicated tool `rt-aurix-lite/protocol/tools/generate.py`, which reuses the canonical
protocol logic by import **without modifying any file under `protocol/`** — so the existing
RT/SYS tooling and workflow are completely untouched.

From the repository root:

```bash
# Validate the subset (no frozen baseline in a subset)
python rt-aurix-lite/protocol/tools/generate.py validate

# Generate codecs / manifests / Python / TypeScript / C++
python rt-aurix-lite/protocol/tools/generate.py generate

# Verify current (read-only)
python rt-aurix-lite/protocol/tools/generate.py generate --check

# Generate derivative artifacts (DBC, CSV, Markdown docs)
python rt-aurix-lite/protocol/tools/generate.py derive

# Inspect a message
python rt-aurix-lite/protocol/tools/generate.py inspect 0x204
```

> The canonical protocol tools (`protocol/tools/protocol.py`, `export_dbc.py`,
> `export_csv.py`, `export_docs.py`) are **not** modified and are not required to build or
> regenerate this subset.

## Contract files

| File | Contents |
| --- | --- |
| `network.yaml` | buses (high, low @ 500 kbit/s), nodes, gateway routes |
| `rta.yaml` | all RT-owned messages (drive, state, pid, steer/brake diag, safety sts, mode, diag, heartbeat) |
| `host.yaml` | Jetson/Host-originated messages (drive, brake, light, steer, obstacle, heartbeat) |
| `mtr.yaml` | MTR-originated messages (throttle sts, motor fbk) |
| `ses.yaml` | EPS-C steer-by-wire vendor protocol (command + status + error + version + test) |
| `seb.yaml` | SEB brake-by-wire vendor protocol (command + status + error + version + test) |
| `hmi.yaml` | HMI mode/power requests (receivers: RT, Host) |

## Generated hashes

- `SEMANTIC_HASH` / `WIRE_HASH`: content hash of canonical wire facts (layout/codec).
- `NETWORK_HASH`: buses + routes + bus instances.

Printed by `protocol.py generate`/`validate` and embedded in the generated code.
