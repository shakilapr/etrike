\begin{tcolorbox}[mobilesection, title=1. Universal Grammar Formula]
\footnotesize
The WS2812 emits \textbf{one color at any instant}. Multi-state messages replace base color with a short diagnostic overlay pip ($200\,\text{ms}$):
\begin{center}
\textbf{Color (Where)} $\times$ \textbf{Cadence / Pip (What)}
\end{center}
{\scriptsize Zero Magenta used to eliminate optical ambiguity with Purple.}
\end{tcolorbox}

\midrule

\begin{tcolorbox}[mobilesection, title=Hardware \& Implementation Notes]
\tiny
\begin{itemize}\setlength{\itemsep}{0pt}\setlength{\parskip}{0pt}
  \item \textbf{Diode}: Addressable WS2812 on GPIO 48 of \texttt{sys-esp32} and \texttt{rt-esp32}.
  \item \textbf{Evaluation Rate}: 25\,Hz (40\,ms) deterministic loop in \texttt{task\_indicator} \& \texttt{control\_task}.
  \item \textbf{Brightness}: 25\% clamp ($I_{max}=64$) with quadratic gamma $I = x^2/256$ on breathing.
\end{itemize}
