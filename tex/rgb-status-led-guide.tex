\begin{tcolorbox}[sectionbox, title=1. Visual Grammar: Domain Color $\times$ Temporal Modulation]
The onboard WS2812 diode emits \textbf{one color at any instant}. Multi-state messages are signaled by \textbf{temporally replacing the base color} with a short diagnostic overlay pip ($200\,\text{ms}$):
\begin{center}
\textbf{What You See} $=$ \textbf{Domain Base Color} (Where / Subsystem) $\times$ \textbf{Temporal Modulation} (Cadence \& Pip / What Is Happening)
\end{center}
Both controllers share identical color palettes and pip semantics. Magenta is completely eliminated to ensure zero optical confusion with Purple.
\end{tcolorbox}

\begin{tcolorbox}[sectionbox, title=3. Hardware \& Implementation Notes]
\scriptsize
\begin{itemize}\setlength{\itemsep}{0pt}\setlength{\parskip}{0pt}
  \item \textbf{Physical Diode}: Addressable WS2812 RGB LED located on GPIO 48 of both \texttt{sys-esp32} and \texttt{rt-esp32} development boards.
  \item \textbf{Timing \& Evaluation Rate}: Update loop executes deterministically at \textbf{25\,Hz (40\,ms cycle)} in \texttt{task\_indicator} (SYS) and \texttt{control\_task} (RT).
  \item \textbf{Optical Isolation}: Breathing cadences use quadratic gamma curve $I = x^2 / 256$ to ensure smooth human-eye response. Solid/Blink cadences clamp to $25\%$ intensity to prevent glare in dimly lit lab environments.
\end{itemize}
